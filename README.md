# SunJob — сайт

Лендинг SunJob: работа в отелях Турции, Египта и Северного Кипра для кандидатов из Казахстана.

- Языки: русский и казахский (переключатель в шапке, `?lang=kk` открывает казахскую версию)
- Заявки: квиз и кнопки ведут в WhatsApp
- Хостинг: GitHub Pages (ветка `main`, корень репозитория)

## Структура
- `index.html` — страница
- `css/site.css` — стили
- `js/app.js` — логика, анимации, квиз
- `js/i18n.js` — тексты на казахском и списки на двух языках
- `img/`, `vid/` — фото и видео (данные на визах размыты)
